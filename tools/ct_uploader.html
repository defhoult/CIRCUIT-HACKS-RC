Circuit Tracks Uploader

Sends only SHA-256 verified firmware to the Circuit Tracks, with the same protocol as Novation Components.

Before you start

  1. Close Novation Components and any DAW or MIDI program (on Windows only one application can open the port).
  2. Connect the Circuit Tracks directly by USB and power it on in bootloader mode: hold Scales + Preset + Note while switching it on. With firmware running, the transfer can report "success" and the unit keeps the previous version (Beta 5.39, 2026-11-08).
  3. Do not unplug power or USB during the transfer.
